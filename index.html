조작법

모든 키는 지금 보이는 방향 기준입니다. 정면에 보이는 면이 F입니다.

W + ← / →윗층 왼쪽(U) / 오른쪽(U')
S + → / ←아래층 오른쪽(D) / 왼쪽(D')
D + ↑ / ↓오른쪽 줄 위로(R) / 아래로(R')
A + ↓ / ↑왼쪽 줄 아래로(L) / 위로(L')
E / Q앞면 시계(F) / 반시계(F')
Z / C뒷면 B / B'
← → ↑ ↓ 만보는 방향 바꾸기 (큐브는 그대로)
Shift + 방향키큐브 전체 돌리기 (x, y)
Shift + E/Q큐브 전체 기울이기 (z / z')
숫자 2~4 후 이동키안쪽 층만 돌리기 (4×4 이상, 3×3 가운데층)
Shift + WASD 조합바깥 2층 함께 (Rw, Uw…)
Space / Enter스터디: 다음 한 수 / 현재 공식 끝까지 자동
Backspace되돌리기

마우스: 스티커를 끌면 그 줄이 돌아가고, 빈 곳을 끌면 시점이 바뀝니다. 터치도 같습니다.
